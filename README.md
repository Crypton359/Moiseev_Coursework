# Курсовой проект — вариант №16 «Гараж»

Система на Arduino Uno контролирует концентрацию газа (MQ-2), движение (PIR) и положение ворот (SW1). При значении газа выше 50 ppm включаются реле вытяжки и красный светодиод. Опрос датчиков выполняется каждые 5 секунд.

**Проект Wokwi:** https://wokwi.com/projects/478582994646665217

## Используемые программы

EasyEDA, Wokwi, Arduino, Node-RED, SQLite, Git.

## Основные файлы

| Путь | Назначение |
|---|---|
| `sim/diagram.json` | Схема в Wokwi |
| `firmware/variant_16.ino` | Программа Arduino |
| `db/schema.sql` | Структура базы данных |
| `db/queries.sql` | Проверочные SQL-запросы |
| `db/variant.db` | База данных SQLite |
| `nodered/flow.json` | Поток обработки данных |
| `data/log.txt` | Журнал показаний |
| `data/log_fault.txt` | Журнал для проверки неисправности |
| `docs/` | Схемы, расчёты и скриншоты |

## Порядок запуска

1. Открыть проект Wokwi по ссылке и запустить симуляцию.
2. Скопировать строки `DATA` и `EVENT` из Serial Monitor в файл `data/log.txt` и сохранить его.
3. Запустить `start-nodered.bat` и открыть `http://localhost:1880`.
4. Если поток ещё не загружен, импортировать `nodered/flow.json` и нажать **Deploy**. После сохранения `data/log.txt` Node-RED загружает показания в SQLite.
5. Посмотреть данные командой из папки проекта:

   ```cmd
   sqlite3 db\variant.db ".read db\queries.sql"
   ```

Если базы данных ещё нет, предварительно создать её командой:

```cmd
sqlite3 db\variant.db ".read db\schema.sql"
```

## Тестовый режим

Переключатель **SW2** включает режим `TEST`. Команда `SET 30` или `SET 80` в Serial Monitor задаёт тестовую концентрацию газа. В обычном режиме `AUTO` используются показания MQ-2. Режим отмечается в журнале и базе данных полем `mode`.

События `THRESHOLD` и `NORMAL` создаёт Arduino, а `FAULT` при недопустимых показаниях — Node-RED. Для проверки неисправности используется `data/log_fault.txt`.
